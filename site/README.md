# Energia — концептуальная одностраничная демонстрация

Основной дизайн — Amber Orbit: тёплый эспрессо, янтарь, медь и звёздная тема. Статический сайт на русском языке без внешних зависимостей. Содержит художественную SVG-схему сети, иллюстрацию JeromiPAD, минутный таймер и арифметический макет обмена тестовых единиц. В интерфейсе явно обозначены научные и технические ограничения; никаких платежей, криптокошельков, реальных обменов, медицинских или финансовых обещаний нет.

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory site/dist
```

Затем открыть http://127.0.0.1:8000. Остановить сервер: Ctrl+C.

Файлы публикации: `dist/index.html`, `dist/main.css`, `dist/designs/design.css`, `dist/designs/demo.js`, `dist/app.js`. Сайт не обращается к внешним службам, не хранит пользовательские данные и не подключён к реальным устройствам. Таймер работает только пока открыта страница, восстанавливая отсчёт по времени после фоновой приостановки браузера. Сброс останавливает текущий отсчёт.

ARM — система программирования катушек в концепции проекта. Здесь представлен её демонстрационный командный язык; реальный аппаратный протокол ещё не предоставлен. ARM проекта не связан с архитектурой процессоров Arm. Код ARM на основной странице повторяет исполнимый пример `energia_demo/example.arm` и меняет только состояния симуляции. Роли и доли — симуляция, не юридическое распределение собственности. DEMO-ETH не является Ethereum. SVG — иллюстрации концепта, не фотографии изготовленного браслета.

Поддержаны адаптивная вёрстка, клавиатурная навигация, skip-link, подписи элементов и prefers-reduced-motion. Браузерная визуальная проверка в текущем окружении не выполнена; перед публикацией проверить на телефоне и компьютере. Автоматическая публикация и серверная конфигурация в эту локальную подготовку не входят.

## Галерея концепта

Страница ожидает 25 изображений `dist/assets/jeromi-pad-01.png` … `dist/assets/jeromi-pad-25.png`. Первые шесть показаны сразу; остальные 19 раскрываются кнопкой «Показать ещё 19 визуализаций». Изображения загружаются лениво, каждое ведёт на полноразмерный файл. Все изображения обозначены как AI-визуализации концепта, а не фотографии готового устройства. Перед публикацией необходимо добавить файлы и проверить доступность всех 25 изображений.

## Альтернативные дизайн-концепции

`dist/designs/index.html` — выбор двух вариантов; `amber.html` — эспрессо и янтарь, `plum.html` — слива, роза и шампань. Каждый содержит анимацию виртуальных блоков между JeromiPAD и Type 1/2/3 и независимую браузерную симуляцию получения тестовых Jeromi и обмена на DEMO-ETH. Все значения локальны и сбрасываются при обновлении. Сеть, оборудование и реальные ETH не подключены. Основным выбран Amber Orbit; оба альтернативных предложения доступны в `designs/`.
