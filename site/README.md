# Energia — концептуальная одностраничная демонстрация

Статический сайт на русском языке без внешних зависимостей. Содержит художественную SVG-схему сети, иллюстрацию Jeremy Pad, минутный таймер и арифметический макет обмена тестовых единиц. В интерфейсе явно обозначены научные и технические ограничения; никаких платежей, криптокошельков, реальных обменов, медицинских или финансовых обещаний нет.

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory site/dist
```

Затем открыть http://127.0.0.1:8000. Остановить сервер: Ctrl+C.

Файлы публикации: `dist/index.html`, `dist/styles.css`, `dist/app.js`. Сайт не обращается к внешним службам, не хранит пользовательские данные и не подключён к реальным устройствам. Таймер работает только пока открыта страница, восстанавливая отсчёт по времени после фоновой приостановки браузера. Сброс останавливает текущий отсчёт.

ARM в тексте — проектный DSL, не архитектура Arm. Код на странице — иллюстративный псевдокод. Роли и доли — симуляция, не юридическое распределение собственности. DEMO-ETH не является Ethereum. SVG — иллюстрации концепта, не фотографии изготовленного браслета.

Поддержаны адаптивная вёрстка, клавиатурная навигация, skip-link, подписи элементов и prefers-reduced-motion. Браузерная визуальная проверка в текущем окружении не выполнена; перед публикацией проверить на телефоне и компьютере. Автоматическая публикация и серверная конфигурация в эту локальную подготовку не входят.
