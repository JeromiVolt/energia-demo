# Математическая записка: семь проверяемых моделей

Дата: 23 октября 2026 года. Обозначения проекта: Jeromi, JeromiPAD,
sbela76. Названия не меняют физические единицы и предпосылки уравнений.
Ниже приведены общеизвестные модели и условные вычисления, а не измерения
устройств Type 1–3 и не доказательства заявленных свойств проекта.
Все числа выбраны для иллюстрации. Документ не является схемой сборки оборудования.

## 1. Идеальный LC-контур: вывод резонансной частоты

Для сосредоточенного контура без потерь закон напряжений даёт
`L q″ + q/C = 0`, где `i = q′`. Подстановка `q(t) = Q cos(ω₀t + φ)`
даёт `−Lω₀² + 1/C = 0`. Следовательно:

```text
ω₀ = 1/√(LC),    f₀ = ω₀/(2π).
```

Проверка размерности: `[Гн] = В·с/А`, `[Ф] = А·с/В`, поэтому
`[LC] = с²`, `[ω₀] = с⁻¹`, `[f₀] = Гц`. Радиан безразмерен.

Условный пример: `L = 0.01 Гн`, `C = 10⁻⁹ Ф`:

```text
LC = 10⁻¹¹ с²
ω₀ ≈ 316227.766 с⁻¹
f₀ ≈ 50329.212 Гц.
```

Это частота идеализированной модели. Паразитные параметры, нагрузка,
геометрия, связь контуров и нелинейность меняют поведение реального устройства.
Резонанс сам по себе не означает квантовые вычисления или появление энергии.

## 2. Баланс энергии на фиксированной границе

Для одной выбранной системы и интервала `[t₀,t₁]`:

```text
ΔU = ∫(P_in − P_out − P_loss) dt
E_in = E_out + E_loss + ΔU.
```

Все слагаемые второго равенства имеют единицу Дж. Мощность измеряется в
Вт = Дж/с. Потоки наружу и потери здесь определены неотрицательными;
`ΔU` может быть отрицательной при разряде накопителя.

Условный пример: за 10 с средний вход 10 Вт даёт `E_in = 100 Дж`.
При потерях 30 Дж и росте запаса на 10 Дж полезный выход составляет
`E_out = 100 − 30 − 10 = 60 Дж`; средняя выходная мощность — 6 Вт.
Доля выхода относительно входа — 0.6. При разряде накопителя выход может
временно превышать текущий вход; тогда требуется учитывать отрицательное `ΔU`.

Для проверки нужны синхронные измерения всех потоков, начального и конечного
запаса и неопределённостей приборов. Демобаланс Jeromi имеет другую природу:
между «одним блоком» и одним джоулем соответствие не установлено.

## 3. RLC: затухание, возбуждение и энергетическое тождество

Для линейной последовательной цепи с постоянными `L,C,R > 0`:

```text
L q″ + R q′ + q/C = V_drive(t)
U = L i²/2 + q²/(2C),     i = q′
dU/dt = i(L q″ + q/C) = V_drive i − R i².
```

Каждый член первого уравнения имеет единицу В; каждый член последнего —
Вт. Например, `[R i²] = Ом·А² = В·А = Вт`. При `V_drive = 0`
производная энергии неположительна. При внешнем возбуждении источник
вносит мощность `V_drive i`; управляющая команда сама по себе её не создаёт.

При свободном недозатухающем движении:

```text
α = R/(2L)
ω_d = √(1/(LC) − α²),    условие: α < ω₀
q(t) = exp(−αt) [A cos(ω_d t) + B sin(ω_d t)].
```

Для предыдущих `L,C` и условного `R = 100 Ом`:
`α = 5000 с⁻¹`, `ω_d ≈ 316188.235 с⁻¹`, время уменьшения
огибающей заряда в `e` раз — `1/α = 0.0002 с`.
При других начальных условиях меняются `A,B`, но энергетическое тождество
остаётся тем же. Оно следует непосредственно из уравнения цепи.

## 4. Нормировка состояния и роль комплексной фазы

Пусть ортонормированный базис удовлетворяет `⟨j|k⟩ = δ_jk`.
Для `|ψ⟩ = α|0⟩ + β|1⟩` раскрытие скалярного произведения даёт:

```text
⟨ψ|ψ⟩ = |α|² + |β|² = 1.
```

Амплитуды безразмерны. Например, `α = √3/2`, `β = exp(iφ)/2`:
сумма квадратов модулей равна `3/4 + 1/4 = 1` при любой вещественной
фазе `φ`. Это математическое состояние, а не состояние доказанного
физического кубита внутри катушки.

Строки программы `0` и `1`, одновременно хранимые в памяти, не реализуют
такое состояние. Нужны физический носитель, подготовка и измерения.

## 5. Правило Борна и проверяемое различие базисов

Для нормированного состояния и проективного измерения:

```text
P(m) = ⟨ψ|Π_m|ψ⟩,   Π_m = |m⟩⟨m|
P(m) = |⟨m|ψ⟩|².
```

Вероятности безразмерны. Для состояния предыдущего раздела измерение
в базисе `|0⟩, |1⟩` даёт `P(0)=3/4`, `P(1)=1/4`.
Это вероятности результатов отдельных измерений, не два результата
одновременно и не частоты, гарантированные в каждой конечной выборке.

В другом базисе `|±⟩ = (|0⟩ ± |1⟩)/√2`:

```text
P(+) = |(α+β)/√2|² = 1/2 + (√3/4) cos φ
P(−) = 1/2 − (√3/4) cos φ
P(+) + P(−) = 1.
```

Фаза, незаметная при измерении в первом базисе, влияет на второй.
Численный расчёт этих величин демонстрирует математику; воспроизведение
формулы на обычном компьютере не является экспериментом с аппаратным кубитом.

## 6. CHSH: вывод классической границы и условный квантовый пример

В локальной модели скрытой переменной `λ` результаты `A,A′,B,B′`
принимают значения `±1`, а выборы настроек независимы от `λ`.
Для фиксированного `λ`:

```text
s(λ) = AB + AB′ + A′B − A′B′
     = A(B+B′) + A′(B−B′).
```

Поскольку `B,B′ = ±1`, одна скобка равна нулю, другая — `±2`.
Значит `|s(λ)|=2`; усреднение даёт
`|S| = |E(a,b)+E(a,b′)+E(a′,b)−E(a′,b′)| ≤ 2`.

Для идеального двухкубитного синглета и измерений спина в одной плоскости
квантовое предсказание имеет вид `E(a,b)=−cos(a−b)`.
При углах `a=0°`, `a′=90°`, `b=45°`, `b′=−45°`:

```text
E(a,b) = E(a,b′) = E(a′,b) = −1/√2
E(a′,b′) = +1/√2
S = −2√2,    |S| ≈ 2.828427.
```

Все корреляции и `S` безразмерны. Предел `2√2` относится к указанной
квантовой постановке. Для экспериментального вывода нужны сырые совместные
результаты, независимые настройки, статистика, учёт детекции и остальных
предпосылок теста. Распечатать `2√2` в программе недостаточно.
Этот пример не устанавливает запутанность между устройствами проекта
и не задаёт канал передачи энергии или сообщений.

## 7. Реестр симулятора: инвариант и доказательство по операциям

Обозначим `B_i` — текущие демокредиты владельца, `I` — суммарную эмиссию,
`R` — суммарно погашенные демокредиты, `H_i` — невыводимые DEMO-ETH,
`k = 0.001 DEMO-ETH/демокредит`. Инварианты реализации:

```text
Σ B_i + R = I,       B_i ≥ 0
Σ H_i = kR.
```

Изначально все величины равны нулю. При условной медитации с начислением
`c > 0` операции `B_i ← B_i+c`, `I ← I+c` сохраняют первое равенство;
второе не меняется. При демонстрационном обмене `0 < d ≤ B_i`:

```text
B_i ← B_i−d,    R ← R+d,    H_i ← H_i+kd.
```

Тогда изменение `ΣB_i+R` равно `−d+d=0`; изменение обеих сторон
второго равенства равно `kd`. Неотрицательность следует из проверки
`d ≤ B_i`. Поэтому последовательность разрешённых операций сохраняет
инварианты по индукции. Управление устройствами не меняет этот реестр.

Условный пример: 20 минут дают 20 демокредитов. Обмен 5 единиц оставляет
`B_a=15`, `R=5`, `I=20`, `H_a=0.005 DEMO-ETH`. Проверки:
`15+5=20` и `0.005=0.001×5`. Другие владельцы сохраняют нулевые балансы.
Коэффициент не является рыночной котировкой Jeromi/ETH; DEMO-ETH не Ethereum.

Реализация использует Decimal и ограничения входной точности; она не является
промышленным финансовым реестром. Переводы между пользователями, идемпотентность
входящих событий и долговечное хранилище здесь не реализованы. Эти требования
нельзя объявлять выполненными по доказательству для двух существующих операций.
