# Energia · Jeremy Pad

Исследовательская концепция и открываемый в браузере демонстрационный прототип.
Это новая программная модель по описанию проекта, а не публикация существующей
прошивки: исходники оборудования и его протокол пока не предоставлены.

## Что работает

- Офлайн-модель устройств Type 1/2/3 и четырёх условных областей по 25%.
- Проверка принадлежности команд, журнал, тестовые балансы и демонстрационный обмен.
- Адаптивный одностраничный сайт с таймером медитации и анимацией сигналов.

Нет подключения к оборудованию, кошелькам или Ethereum. DEMO-ETH не имеет стоимости.
Нет приёма денег, предзаказов и обещаний дохода. Медицинские и квантовые свойства
устройств этой демонстрацией не установлены. ARM — проектное название командного
интерфейса; его ограниченный язык исполняется только в симуляторе. Аппаратного адаптера нет.

## Запуск

Требуется Python 3.10+; установка сторонних пакетов не нужна.

```bash
python3 -m energia_demo
python3 -m unittest discover -s tests -v
python3 -m http.server 8080 --bind 127.0.0.1 --directory site/dist
```

Откройте http://127.0.0.1:8080. Это локальный просмотр, не производственный сервер.
